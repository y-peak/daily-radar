怎么写论题卡

服务器上编辑 data/thesis.json，key 用 secid（如 1.600519）：

{
  "updated_at": "{{ data.get('generated_at', '')[:10] }}",
  "items": {
    "1.600519": {
      "statement": "一句话论题（必须能被证伪）",
      "pillars": [
        {"text": "海外订单环比继续增长", "status": "on_track", "note": "Q2 环比 +12%"},
        {"text": "毛利率站上 35%", "status": "behind", "note": "Q2 33.8%"}
      ],
      "risks": ["海外需求不及预期：订单连续两季环比下滑即认错"],
      "exit": "2026Q3 毛利率 <35% 或大客户订单同比转负",
      "catalysts": [{"date": "{{ data.get('generated_at', '')[:4] }}-10-31", "text": "三季报"}],
      "updated_at": "{{ data.get('generated_at', '')[:10] }}"
    }
  }
}
  • status 只有三个值：on_track（达标）、behind（走弱）、pending（待验证）—— 认不出的一律按待验证算，不猜。
  • risks 不能空：写不出"什么情况下我认错"，它就不是论题，是口号。空着页面会明确标出来。
  • 超过 90 天没更新会提示该复盘 —— 一张半年没动过的卡，信息量等于没有。
